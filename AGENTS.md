# Instrucciones del proyecto

- Lee `MEMORIA.md` antes de modificar el proyecto para conocer su estado y las decisiones previas.
- Actualiza `MEMORIA.md` en cada entrega que cambie código, contenido, diseño, configuración o estado de publicación. Mantén el resumen vigente y añade una entrada breve al historial: fecha, cambio, validación y si quedó local o publicado.
- Distingue lo implementado, lo pendiente y lo publicado. No marques un despliegue como completado sin comprobar GitHub Actions y la versión pública.
- Trabaja en local y publica solo cuando el usuario lo autorice. Consulta el estado vigente en `MEMORIA.md`.
- Mantén la experiencia en español, prioriza Android y respeta las preferencias de movimiento y sonido. Evita rachas, penalizaciones y cuidados obligatorios.
- Conserva la compatibilidad de las partidas y copias existentes. Las flores especiales, decoración y recuerdos permanentes no deben borrarse con el reinicio diario.

Estas instrucciones documentan la petición del usuario de mantener una memoria del trabajo. Sus instrucciones posteriores tienen prioridad.
